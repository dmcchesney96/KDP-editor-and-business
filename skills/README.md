# Skills

Each skill owns one bounded transformation. Use the narrowest skill that fits.

## Market
1. `kdp-market-opportunity-scout` — idea/niche → evidence-aware opportunity scan.
2. `kdp-competitor-benchmark` — comparable books → competition benchmark.
3. `kdp-review-gap-miner` — reviews/feedback → reader-need and white-space map.
4. `kdp-opportunity-decision-brief` — research packet → proceed/test/revise/hold/stop decision.

## Product strategy
5. `kdp-product-positioning-architect` — validated evidence → approved product brief.

## Content research and integrity
6. `child-development-content-researcher` — child audience/product goal → developmental design rules.
7. `christian-kids-content-researcher` — Christian children's product goal → biblical content research packet.
8. `bible-content-integrity-checker` — proposed/final Christian content → independent integrity audit.

## Workbook development
9. `kdp-workbook-architect` — approved brief/research → complete workbook blueprint.
10. `activity-design-generator` — approved page map → detailed original activity specs.
11. `children-workbook-editor` — workbook content/page specs → edited QA-ready content.

## Design strategy
12. `kdp-interior-design-system` — approved architecture + audience/print constraints → reusable interior visual system.
13. `kdp-cover-strategy` — defined product + competitor-cover evidence → conversion-aware cover creative brief.

## Publishing / production QA
14. `kdp-product-economics-planner` — final/proposed print specs → current price/royalty scenarios.
15. `kdp-keyword-metadata-optimizer` — finished/defined book + reader language → compliant metadata recommendations.
16. `kdp-category-positioning` — finished book + market context → accurate current category recommendations.
17. `kdp-listing-copywriter` — finished book + positioning → truthful product-page copy.
18. `kdp-print-preflight` — final interior/cover → current-KDP print-readiness report.
19. `kdp-publishing-package-validator` — final files + metadata + policy checks → upload/publish readiness gate.

## End-to-end rule

For an explicit full children's Christian workbook project, default sequence:

`market scout → competitor benchmark → review-gap miner → decision brief → product positioning → child-development research + Christian-content research → workbook architecture → activity design → children's workbook edit + Bible integrity check → interior design system + cover strategy → artifact production → print preflight → economics → metadata → categories → listing copy → publishing-package validation`

Do not chain every skill for a simple question. Do not mass-generate pages before architecture. Do not let creation substitute for independent QA.

Current official Amazon KDP documentation outranks stale repository rules. Subject-matter research should use the strongest available sources for that domain.
