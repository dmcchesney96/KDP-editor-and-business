# KDP Interior Design System

## Job
Own: `APPROVED ARCHITECTURE + AUDIENCE / PRINT CONSTRAINTS → INTERIOR DESIGN SYSTEM`

## Define
- trim and bleed assumptions;
- safe-area and margin rules;
- typefaces and minimum practical sizes;
- heading/instruction/body hierarchy;
- activity-box conventions;
- tracing-line treatment;
- answer/response areas;
- icon/illustration language;
- line weights and grayscale/color behavior;
- whitespace/page-density targets;
- recurring navigation/page labels;
- footer/page-number rules;
- accessibility/readability conventions;
- reusable templates by page family.

## Children's workbook rules
As relevant:
- one dominant action per activity page;
- child-facing instructions visually separate from adult prompts;
- generous writing/marking space;
- strong figure-ground contrast;
- no decoration that looks like an answer target;
- consistent placement of repeated interaction patterns;
- adult-support cues should not compete with the child's task.

## Guardrails
- Current KDP technical rules outrank this system.
- Do not let aesthetic consistency create monotonous page mechanics.
- Never shrink text or response areas merely to preserve a template.
- Production tooling implements the system; this skill does not certify final PDFs.
